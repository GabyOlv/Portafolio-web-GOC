# Portafolio-web-GOC

Portafolio web de **Gaby Olvera**, diseñadora y desarrolladora en México.
Muestra proyectos profesionales y personales de identidad visual, branding
y diseño editorial.

## Características

- Sitio de una sola página con cinco secciones: Inicio, Sobre mí,
  Proyectos, Servicios y Contacto
- Diseño responsivo (escritorio, tableta y celular)
- Buscador integrado en la barra de navegación
- Botones flotantes para moverse entre Logofolio, Branding y Editorial
- Imágenes optimizadas en formato WebP
- Protección de imágenes: marca de agua "© Gaby OC" y bloqueo de
  descarga directa

## Tecnologías

HTML5 · CSS3 · JavaScript (sin frameworks ni dependencias)

## Estructura

```
├── index.html
└── assets/        # imágenes en WebP
```

## Uso

Descarga o clona el repositorio y abre `index.html` en tu navegador.
No requiere instalación.
